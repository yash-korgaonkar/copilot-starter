# Basketball Pong

A two-player basketball-themed Pong game built with Java Swing. Both players
share the keyboard:

- Player 1: `W` and `S`
- Player 2: Up and Down arrows

The first player to score 5 points wins. The ball gets faster every 10 seconds
of active play. Press `Enter` after a match to start again.

## Run

Requires a Java Development Kit (JDK 8 or newer).

```text
javac -d target src\BasketballPong.java
java -cp target BasketballPong
```
